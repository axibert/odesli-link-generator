# Privacy Policy - Odesli Link Generator

**Last updated:** 25.11.2026

The Chrome extension has no server of its own and collects no personal information. To convert a link it sends the music URL to song.link and, for the right-click entries, track title and artist to Apple's public iTunes Search API. Full text: [privacy-policy.html](https://axibert.github.io/odesli-link-generator/privacy-policy.html)
