Privacy Policy - Odesli Link Converter

Last updated: July 11, 2025

Information We Collect

This Chrome extension does not collect, store, or transmit any personal information. The extension only:

  • Reads the current tab URL when you click the convert button
  • Sends this URL to the Odesli API (song.link) for music link conversion
  • Displays the converted universal link to you
  • Temporarily stores conversion history locally in your browser

Data Usage

The Odesli Link Converter extension:

  • Does not collect or store personal data
  • Does not track user behavior or analytics
  • Does not use cookies
  • Only processes music URLs for conversion purposes
  • Does not share data with third parties (except Odesli API)

Third-Party Services

This extension uses the Odesli API (song.link) to convert music links between streaming platforms. When you convert a link, the URL is sent to Odesli's servers for processing. Please refer to Odesli's privacy policy for information about their data handling practices.

Permissions Used

  • activeTab: To read the current tab's URL for conversion
  • storage: To save user preferences locally
  • host_permissions: To communicate with the Odesli API

Data Security

All data processing happens locally in your browser or through secure HTTPS connections to the Odesli API. No sensitive information is stored or transmitted.

Contact

If you have questions about this privacy policy, please contact us through the Chrome Web Store developer contact information.

Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the "Last updated" date above.
